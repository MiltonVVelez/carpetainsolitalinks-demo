
# Link Page for a Small Digital Magazine 

This project creates a landing page for a business's Instagram account that connects users to all of the brand's social media profiles.



## Features

- Mobile-First & Responsive Layout: Formatted specifically for mobile screens and Instagram's in-app browser.
- Centralized Social Hub: Direct links to all brand channels
- Easily customisable colors, fonts,and social icons to fit any brand identity.



## Tech Stack

* **Front-End** HTML, CSS , JavaScript

* **Styling:** FontAwesome (for icons), FlexBox

* **Hosting**: Netlify Pages :
